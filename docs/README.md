# esp32-face-pause 설계 문서

> **얼굴이 보이면 재생, 얼굴이 사라지면 일시정지.**
> XIAO ESP32S3 Sense가 카메라로 얼굴을 검출하고, 그 결과를 MQTT로 보내면 웹 페이지의 유튜브 플레이어가 재생/일시정지된다.

원본 기획(Zero-Touch Media Control)은 "시선"을 기준으로 하지만, 이 프로젝트는 **얼굴 검출 여부**를 기준으로 한다.
정면 얼굴 위주로 학습된 모델은 고개를 옆으로 돌리면 얼굴을 놓치기 때문에, 결과적으로 "화면을 보면 재생, 고개를 돌리면 정지"라는 기획 의도와 거의 같게 동작한다.

## 핵심 설계 결정

1. **영상은 ESP32를 떠나지 않는다.** ESP32가 직접 얼굴을 검출하고 `present / absent` 같은 작은 결과만 보낸다.
2. **디바운스는 ESP32에서 한다.** 한두 프레임 놓쳤다고 영상이 멈췄다 켜졌다 하지 않도록, 상태 전환은 펌웨어(팀원 2)가 결정한다. 웹은 받은 상태를 반영만 한다.
3. **경계는 두 개의 약속뿐.** 보드 안은 `face_result.h`(쪽지 양식), 보드 밖은 MQTT 토픽([03-messages.md](03-messages.md)). 이 약속만 지키면 서로 기다리지 않고 개발할 수 있다.
4. **Arduino + Edge Impulse.** XIAO ESP32S3 Sense에서 가장 자료가 많은 조합이다. 컴파일 확인은 `fw` 컨테이너(arduino-cli), 업로드는 각자 Arduino IDE로 한다.
